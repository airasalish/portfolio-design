How I work

Watch, test, build, ship

The same four steps, whether it's a video pipeline or an internal tool.

01

Watch the work

People describe the problem; the work shows it. At BabyBillion "output is slow" turned out to be small steps repeated for every single video.

→ found the real bottleneck
02

Test the tools

I try the new AI tools, then test them against real use, not demos: graded test sets, failure cases, a clear bar to pass. That includes vision models reading real photos and posters.

→ 35% fewer wrong answers
03

Build the small thing

The smallest tool that removes the step: a Python script, an n8n flow, a prompt system that keeps a look consistent.

→ 50+ workflows automated
04

Ship it, write it down

Deployed so people can open it, with a guide they can follow without me. A tool nobody uses isn't finished.

→ playbook the team adopted
