# Design portfolio

The design-focused version of my portfolio: https://aira-salish-design.vercel.app

It shows the visual side of my work (video, posters, product UI) and includes a design résumé in `docs/`. It's plain HTML, CSS and JavaScript, and it deploys to Vercel on every push to `main`.

To run it locally:

```bash
python -m http.server 8000
```
